# Tri-City Generals Sports Academy

Astro site adapted from the House36 baseball trainers template for
[tcgenerals.com](https://www.tcgenerals.com/).

## Included

- Responsive homepage with lead forms and current program links
- Six program pages generated from `src/data/prospect.json`
- Three local-area pages for Columbus, Phenix City, and Fort Moore
- Optimized, locally hosted imagery sourced from the existing company website
- Static production output in `dist/`

## Commands

```bash
npm install
npm run dev
npm run build
```

Prospect details live in `src/data/prospect.json`. Shared content and image
mapping live in `src/data/site.ts`.
