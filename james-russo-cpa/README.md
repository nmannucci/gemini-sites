# James J. Russo, CPA

Astro website for James J. Russo, CPA, adapted from the House36 CPA firm template.

Business content and source notes are documented in `BUSINESS_INFO.md`. The website is generated from `src/data/prospect.json` and includes a homepage, six service pages, and six Bay Area county pages.

## Local development

```bash
pnpm install
pnpm dev
```

## Validation

```bash
pnpm build
pnpm test
```
